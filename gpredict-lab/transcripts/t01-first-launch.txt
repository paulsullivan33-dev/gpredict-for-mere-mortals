# First launch, under a virtual display (Xvfb, 1280x960).
# The sandbox has no real screen; Xvfb is a genuine X server
# whose framebuffer we capture with scrot.
$ Xvfb :99 -screen 0 1280x960x24 &
$ DISPLAY=:99 gpredict &

$ xdotool search --name "" getwindowname %@
gpredict
Gpredict: Amateur

# Screenshot: screenshots/first-launch-default-size.png and
# screenshots/main-window.png in this lab. What they show:
# - The default module, "Amateur", opens on its own.
# - A world map with ground tracks and coverage circles for
#   FO-29, SO-50, the ISS and AO-73, plus "Next: AO-91".
# - A polar (radar) view, currently empty, with the next pass
#   counted down: "Next: FO-29 in 24:29".
# - A data panel for AO-73 computed live: azimuth, elevation,
#   slant range, range rate, next event (AOS 2026/11/02
#   21:23:06), footprint, altitude, velocity, Doppler at
#   100 MHz, orbit number 70114.
# - Ground station "sample - Copenhagen, Denmark".

# Read the epoch in TLE1: "21024" = year 2021, day 24.
# The bundled starter data (built into

# run (2026-11-02). Everything the first launch plotted was
# computed from those old elements.
